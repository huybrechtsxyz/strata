# Check Workspace Readiness

Run **Strata: Show Guide** to open the 8-phase readiness checklist.

The guide shows which phases are complete and what to do next:

| Phase | What it checks                |
| ----- | ----------------------------- |
| 1     | Workspace initialized         |
| 2     | Repositories registered       |
| 3     | Profile created and activated |
| 4     | Configuration files present   |
| 5     | All files pass validation     |
| 6     | Build artifacts generated     |
| 7     | SBOM generated                |
| 8     | Deployment executed           |

Each phase includes a hint with the exact command to run if it's not yet complete.

> **Tip:** The status bar at the bottom shows your current phase progress at a glance.
