# Turn on autocomplete and agent skills

**Strata: Update Solution Files** runs `strata sln update`. Run it after installing a new strata
version, so the editor learns about the new fields.

## Autocomplete for every document kind

It exports a JSON Schema per document kind to `.strata/schemas/`. With the
[YAML extension](https://marketplace.visualstudio.com/items?itemName=redhat.vscode-yaml) installed,
you get:

- Completion for `kind`, `meta`, and every `spec` field
- Hover documentation for each field
- Red squiggles on unknown fields while you type, before you even save

## An AI agent that knows strata

It also writes `.claude/skills/strata/SKILL.md`, which Claude Code and GitHub Copilot load
automatically. It teaches them the commands, the merge rules, and the known pitfalls, and tells
them never to deploy or change secrets unless you ask.

Your team's own lessons go in `.claude/skills/project-gotchas/SKILL.md`. Strata creates it once and
never touches it again.

> **Keep your edits:** delete the "Generated by strata" line at the top of the strata skill and
> updates leave it alone.
